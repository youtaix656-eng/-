# 出典・鮮度台帳（コンテンツ品質の裏方メモ）

問題データの**出典**と、毎年変わる**数値の鮮度**を1か所で管理するための台帳。
`npm run validate`（`scripts/validate-content.mjs`）が現状を自動集計するので、
本ファイルは「方針・確認頻度・参照元」を人間向けにまとめる。

## 1. 出典（著作権の扱い）

- 過去問（第25〜34回など）は**著作物**。公開リポジトリに素の問題文を大量常設しない方針。
  - 保持は**派生・自作解説**の形で行う（原問の丸写しを避け、選択肢・正解は事実として保持、解説は自作）。
  - 医療概論の同梱（`src/data/iryouQuestions.js`）は個人利用の範囲。
- 収録バンクと版番号の一覧は `src/data/seedRegistry.js`（単一ソース）。新科目を足したらそこにも追記する。

| 科目バンク | ファイル | 出典の性格 |
|---|---|---|
| 医療概論 | iryouQuestions.js | 同梱（個人利用） |
| 衛生学・公衆衛生学 | eiseiQuestions.js | 過去問→自作教材化 |
| 関係法規 | houkiQuestions.js | 過去問→自作教材化 |
| 解剖学 | anatQuestions.js | 過去問→自作教材化 |
| 生理学 | seiriQuestions.js | 過去問→自作教材化 |
| 臨床医学総論 | rinshoQuestions.js | 過去問→自作教材化 |
| 臨床医学各論 | rinkakuQuestions.js | 過去問→自作教材化 |
| 図問題 | zumondaiQuestions.js | 自作（SVG図） |

## 2. 鮮度管理（毎年変わる数値）

`src/data/mindmapData.js` の `NUMBER_FACTS` のうち `volatile: true` を付けたものが対象。
`asOf` に「いつ時点の値か」を記録する。年1回、下記の一次資料で見直す（`※要確認`）。

| 数値トピック | 主な参照元 | 確認頻度 |
|---|---|---|
| 国民医療費（総額・財源・対国民所得比） | 厚生労働省「国民医療費の概況」 | 毎年 |
| 新規登録結核患者数 | 厚生労働省「結核登録者情報調査」 | 毎年 |
| 平均寿命 | 厚生労働省「簡易生命表」 | 毎年 |
| 健康寿命 | 厚生労働省 健康寿命の算定 | 数年ごと |
| 合計特殊出生率・死因順位・高齢化率 | 「人口動態統計」「人口推計」 | 毎年 |
| 食塩・飲酒などの目標値 | 健康日本21（第三次） | 改定時 |
| 医療計画（5疾病6事業） | 医療計画（第8次・令和6年〜） | 改定時 |
| あはき法の罰金額 | あん摩マツサージ指圧師等法 | 改正時 |

### 見直し手順
1. `npm run validate` を実行し、`■ 数値の鮮度（volatile）` の一覧を確認。
2. 各数値を一次資料で照合し、変わっていれば `NUMBER_FACTS` の `value` と `asOf` を更新。
3. 迷う値は解説に `※要確認` を残す。
