# EarPomo

イヤホン専用・黒背景のみの、静かで瞑想的なポモドーロタイマー。
自分の曲をバックグラウンド再生しながら、余計な情報を削ぎ落として集中する。
**React + TypeScript / Vite / PWA・端末内保存のみ**（公開先：`/-/earpomo`）。

## このアプリの決まり（ここが単一の正。変える時はこのファイルとテストを一緒に直す）

1. **音はイヤホンの確認が取れている時だけ出す。** BGM・開始音・終了音のすべてが対象で、
   確認が無ければ無音のまま（タイマー自体は動く。バイブだけは鳴る）。
   Web には「イヤホンが刺さっているか」を直接教える API が無いので、`src/lib/headphones.ts` は
   `enumerateDevices()` の音声出力の名前に手がかり（headphone／AirPods／Bluetooth 等）がある時だけ
   「見つかった」とし、それ以外は本人の確認（設定の「イヤホンをつけている」）に任せる。
   見つかっていたものが消えた時は確認を外して音を止める。
   **できないことをできるふりに書かない**（設定画面に但し書き。`tests/rules.spec.ts` が文言を見張る）。
2. **背景は `#000000` 固定。** ダーク／ライトの切り替えも配色のカスタマイズも持たない。
   `src/styles.css` の色はすべて R=G=B（灰色だけ）で、グラデーション・影・光彩も持たない（テストが機械チェック）。
3. **残り時間は「終わる時刻」から毎回引き算する**（`src/lib/session.ts`）。1秒ずつ減らさない。
   `session.ts` は時計を読まず、`now` は必ず外から渡す（テストで固定できる）。
   自動で次へ進む時は「前の局面が終わった時刻」から次を始めるので、裏で長く止まっていても
   複数の局面をまとめて追いつき、時間の流れが本物のまま繋がる。
4. **曲は端末の中にだけ置く。** 音声は IndexedDB の `files` ストアに Blob で保存し、`src/lib/storage.ts` は
   ネットワークに触れない（`fetch`／`XMLHttpRequest`／`WebSocket`／`sendBeacon` を持たないことをテストが見張る）。
   初期実装は **1曲選択・ループ・集中中だけ流す**（休憩中は止まる）。シャッフルは持たず、画面にもそう書く。
5. **スケジュールとカレンダーは同じデータ。** `src/lib/schedule.ts` が繰り返し（なし／毎日／平日／毎週）を
   毎回展開し、カレンダーは別の表を持たない。入力は手入力のみ（写真・PDF・OCR は次フェーズ）。
6. **集計は保存しない。** 合計時間・連続達成日数・完了ポモ数・週の推移・タグ別内訳は `src/lib/stats.ts` が
   毎回 `records` から導く（ロジックを直しても過去の記録を読み直せる）。
7. **画像・音声ファイルを持たない。** アイコンは `scripts/gen-icons.mjs`（灰色だけ）、線画は
   `src/components/BreakIllustration.tsx`／`Icons.tsx`、合図音は `src/lib/bell.ts` がその場で作る。
8. **休憩の提案は乱数を使わない**（`src/data/breakTips.ts`。何回目の集中かで順にずらす）。
9. **Wake Lock・端末通知は既定オフ。** どちらも「アプリが生きている間」しか効かない（サーバーを持たないので
   押し通知は無い）。通知は押した時にだけ許可を求める。
10. **日付を UTC で扱わない**（`toISOString()`／`new Date('YYYY-MM-DD')` を使わない。`src/lib/date.ts` で組み立てる）。
11. **画面に出す文にマークダウンを書かない。**

## 画面

| 画面 | 中身 |
|---|---|
| タイマー（ホーム） | 円形の進み具合＋残り時間・POMO n/n・ドット・再生／一時停止・スキップ・BGM・タグ・プリセット名 |
| 休憩（短い／長い） | 一回り小さい灰色の円・線画（机に突っ伏す／仰向け）・過ごし方の提案・スキップ |
| 記録 | 今日／週／月・集中した合計・連続達成日数・完了ポモ数・週の推移（曜日＋日にち）・タグ別内訳 |
| カレンダー | 試験日カード（残り日数・複数登録可）・月表示（予定の日にドット・選択日は白枠）・選択日の予定 |
| スケジュール登録 | 種類（勤務／学校／その他）・日付・開始／終了・繰り返し・メモ・登録済み（今週） |
| 設定 | イヤホンの確認・プリセット（追加／名前／削除）・時間設定・自動で進める・開始音／終了音／バイブ・勉強中BGM・Wake Lock・通知・全消去 |
| 勉強中BGM | フォルダから曲を追加・追加済みの曲（長さ・容量）・無音のまま集中する・音量 |

## 既知の制約（※要確認）

- イヤホン検知：Chrome 系の端末でマイク許可のあとに限られ、iOS Safari は音声出力を列挙しない。有線イヤホンは名前が変わらないことが多い。
- バックグラウンド再生：タイマーは戻った時に正しい残り時間になるが、裏で音が止まる・通知が出ないことがブラウザや端末によってある。

## 開発

```
npm ci
npm run dev      # 開発
npm test         # tsc で .test-build/ へ出してから node --test
npm run build    # tsc && vite build
npm run icons    # PWA アイコンを生成
```
