# クンダリーニトラッカー

継続日数と「チャクラレベル（象徴的な区切り）」を記録し、衝動が来たときに使う道具
（冷却タイマー・呼吸ガイド）を1画面ぶんの距離に置いたアプリ。
**React + TypeScript / Vite / PWA・端末内保存のみ**（公開先：`/-/kundalini`）。

## このアプリの決まり（ここが単一の正。変える時はこのファイルとテストを一緒に直す）

1. **診断しない・治療しない。** 依存症かどうかを判定する仕掛け（チェックリスト・点数）を作らない。
   やめられないことで生活に支障が出ている／落ち込みが2週間以上続く／自分を傷つけたい気持ちがある——
   このときの案内（`src/data/safety.ts` の `HELP_NOTE`）を**弱めない・消さない**。
   3つ以上の画面から見えることを `tests/rules.spec.ts` が機械チェックする。
2. **効果を書かない。** 「◯日続けるとこうなる」は、このアプリに確かめる手立てが無い。
   テストステロン・モテる・若返り・寿命…の類は、テストが名指しで弾く。**割合（◯%）も倍率（◯倍）も持たない。**
3. **チャクラは象徴的な区切り。** `src/data/chakras.ts` の `CHAKRA_DISCLAIMER`
   （医学・解剖学で確かめられたものではない）を、ホームと設定の両方に必ず出す。
   **境界日数に根拠は無い**ので設定から変えられるようにし、画面にも「目安」と書く。
4. **責めない。** リラプスは「失敗」ではなく記録。`意志が弱い／甘え／自業自得／だらしない`
   といった言い方をどのファイルにも置かない（テストが機械チェック。コメント行は落としてから見る）。
5. **リセットで全部を消さない。** 日数が0に戻るのは「いまの継続」だけで、
   **最長記録と通算日数（`src/lib/streak.ts`）は毎回そのつど導く**（保存しない）。
   通算はリラプスしても減らないので、戻った日に「全部消えた」とは見えない。
6. **分析は並べるまで。** `src/lib/analysis.ts` は
   ①原因と結果を矢印で結ばない ②**5段階の平均を出さない**（順番のある目盛りで、間隔が等しいとは限らない）
   ③件数が `MIN_FOR_TREND`（3件）に満たないうちは多い所を強調しない。
   `average`／`mean` という関数を持たないことをテストが見張る。
7. **瞑想の回数・連続日数を数えない**（`src/components/MeditateView.tsx` は記録を残さない）。
   数え始めると、できなかった日を責める道具になる。
8. **緊急ボタンは行き止まりを作らない。** 閉じる口を必ず出し、押した記録は残すが
   「押した＝戻った」ではないと画面に書く。乗り切れなかったときの導線も置く。
9. **端末の中だけ。** `src/lib/storage.ts` は**ネットワークに触れない**
   （`fetch`／`XMLHttpRequest`／`WebSocket`／`sendBeacon` を持たないことをテストが機械チェック）。
   通知・掲示板・アカウントは作らない（サーバーを持たないので約束できない）。
10. **のぞき見よけ（PIN）を暗号化と呼ばない。** 番号は変換して保存する（平文で持たない）が、
    端末内のデータそのものは守られない。**生体認証には対応しない**——できないことを
    できるふりに書かない。番号を忘れたときの出口（消してやり直す）をロック画面自身に置く。
11. **表示名の偽装でできること・できないことを分ける。** 変えられるのはタブの名前とアイコンだけ。
    **ホーム画面に追加済みのアイコンの名前は変えられない**（`manifest.webmanifest` は静的ファイル）。
12. **日付を UTC で扱わない。** `toISOString()` と `new Date('YYYY-MM-DD')` を使わない
    （日本時間の午前0時が前日になる）。日付は `src/lib/date.ts` で組み立てる。
13. **ひとこと（`src/data/words.ts`）に実在の人物の名前を付けない。**
    確かめられない引用は、もっともらしい嘘になる。ここにあるのはこのアプリの言葉。
14. **色だけに意味を持たせない。** 背景は黒で統一し、チャクラの色は点・線・文字にだけ使う。
    レベルは必ず「番号＋名前」と一緒に出し、カレンダーの印は色に加えて形も変える（丸／四角）。
15. **画面に出す文にマークダウンを書かない**（`**強調**` がそのまま表示される。テストが見張る）。
16. **画像ファイル・音声ファイル・外部フォント・グラフのライブラリを持たない。**
    アイコンは `scripts/gen-icons.mjs` が生成し、合図音は `src/lib/bell.ts` がその場で作り、
    グラフは自前の SVG で描く。

## 画面

| 画面 | 中身 |
|---|---|
| ホーム | 日数カウンター／チャクラレベルと7段の一覧／カレンダー（緑＝継続・赤＝リラプス）／開始日時の修正／リラプスの記録 |
| 記録 | 体調・集中力・気分の5段階／その日の気づき（ジャーナル）／リラプスの一覧／ジャーナルのタイムライン |
| 分析 | リラプスの曜日別・時間帯別・きっかけ別／衝動が来た時間帯／継続日数の帯ごとの5段階の分布／これまでの継続 |
| 瞑想 | 呼吸法5つ（ボックス／吐く息を長く／4-7-8／ナディショーダナ／数えない）とタイマー |
| 実績 | 7・14・30・90・180・365日のバッジ（保存せず日数から導く） |
| 設定 | 境界日数／タイマー・音／暗証番号／表示名／書き出し・取り込み・全消去 |
| 緊急ボタン | どの画面からも押せる常設ボタン。冷却タイマー＋呼吸ガイド＋ひとこと |

## データ

保存するのは**入力そのものだけ**（判定結果は保存しない）。

```ts
AppState {
  startedAt: number | null      // いまの継続の開始（epoch ms）
  relapses: { id, at, startedAt, triggers[], note }[]
  days: { [YYYY-MM-DD]: { body, focus, mood, journal } }   // 5段階は未入力=null
  urges: { id, at, seconds, finished }[]                    // 緊急ボタンの記録
  settings: { levelThresholds[7], coolDownSeconds, meditationMinutes, bell,
              pinHash, pinKind, disguise*, lastView }
}
```

レベル・最長記録・通算日数・バッジは、すべてここから毎回導く。

## 開発

```bash
npm install
npm run dev       # 開発
npm run build     # tsc → vite build
npm test          # tsc -p tsconfig.test.json && node --test（48件）
npm run icons     # PWA アイコンを描き直す
```

テストは `tests/*.spec.ts`（TypeScript）。CI が Node 20 のため `tsc` で `.test-build/` へ
出してから `node --test` する（ルートの `npm test` の再帰探索には拾われない名前にしてある）。
