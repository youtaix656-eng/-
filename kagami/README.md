# 鏡（かがみ）

「そう言われると断りにくい」の正体に、名前をつけるためのアプリ。

公開先：https://youtaix656-eng.github.io/-/kagami

人を動かす言い回しには、昔から名前と研究があります。名前を知らないうちは
「自分が弱いからだ」と感じますが、名前がつくと**その場で気づける**ようになります。

**操るための道具ではなく、気づくための道具**です。言われた言葉を貼ると、
54件の型のどれに当たるかを**この端末の中だけ**で調べます。

## できること

| 画面 | 中身 |
|---|---|
| 🔎 貼って調べる | 言われた言葉・届いたメッセージを貼ると、当たった型と**当たった語**が出る。本文のどこに当たったかを印で示す |
| 🪞 自分の言い方を見る | これから送る文章を貼る。使う癖はそのまま人に向く癖になるので、送る前に一度見る |
| 🎭 操作の型 | 54件を8つのまとまりで。なぜ効くのか・見分け方・言われる形・できること・出典 |
| 🛡 返し方 | 10件。**相手を言い負かす言葉は置いていない**（後述） |
| ⊕ 自分の側で起きること | **自分の側の癖**（6件）と、**長く続いた時に起きること**（5件）。落ち度の話にしない・診断しない |
| ☖ 人間分析 | 気になる相手との**距離の決め方**（15件・ふるまい79項目＋共通する芯4つ＋場面5つ）。各型に**黒い心理学での対応策**（`counters`）付き。見たふるまいにチェックすると近い型が出る。**場面（どこで起きたか）でしぼれる。採点しない。**見立ては端末内に保存でき、あとから開いて続きから直せる |
| ✕ 当てにならない見抜き方 | 「本音が読める」とされているもの（7件）。信じると何もしていない人を疑ってしまうので、**信じないための材料**として置く |
| 📝 記録 | いつ・どこで・どの型に当たったか。相手の名前・連絡先は持たない |
| 📇 目次 | 全207項目を読み順（あ〜ん → A〜Z）で。**世に出回っている呼び名（間欠強化・ツァイガルニク効果など）からも引ける**（索引の「→ 見よ」項目） |
| 📚 出典 | どの型がどこから来ているか |

## 決めていること（触るときはここを守る）

1. **点数・危険度・順位を付けない。** 「危険度80点」を出すには他人の事例という
   手元にない基準が要る。出せるのは「どの型の言い回しに、どの語で当たったか」だけ。
2. **当たった＝相手が悪い、ではない。** 同じ言葉はふつうの会話でも使う。
   判定に使った語は必ずそのまま見せる（見せない判定は当てずっぽうの断定と同じ）。
3. **当たらなくても黙らない。** 「短すぎて調べられない」「当たらなかった」を言い分ける。
   当たらない＝問題がない、ではないことも画面に書く。
4. **返し方に「言い負かす言葉」を置かない。** 言い合いは立場が弱い側ほど不利になる
   （言い返せる関係なら、そもそも困っていない）。置くのは相手の同意が要らないことだけ——
   時間を置く・持ち帰る・記録する・人に話す・その場を離れる・窓口に聞く。
5. **出典に URL を書かない。** その場で確かめられない状態でそれらしいリンクを書くのは、
   出典があるように見えて実は無いという、いちばん質の悪い形になる。書名・発表者・年で辿れる形にし、
   確かめきれていないものには `check: true`（画面に「※要確認」）を付ける。
6. **氏名・連絡先を持たない。** 記録は場面（職場／家庭／勧誘／ネット／その他）だけ。
   本文は既定で伏せて保存し、伏せ字で**桁数を数えられないようにする**
   （〔電話番号〕のような札に置き換える。`●●●●` だと別々の番号が形で見分けられる）。
7. **`src/lib/` はネットワークに触れない。** 貼った文面が端末から出ないことの根拠がここ。
   テストが `fetch` などが無いことを機械チェックする。
8. **後読み（lookbehind）を使わない。** 古い Safari が構文エラーになり、読み込みごと落ちる。
9. **色を持たない。** 黒地に白い線（銅版画の図版）の一枚絵として作る。使ってよいのは
   黒・白・その間の灰だけで、`styles.css` の色はすべて R=G=B。テストが機械チェックする。
10. **絵文字を使わない。** 絵文字は環境によって色付きで描かれるので、モノクロが崩れ、
   しかも端末ごとに形が変わる。画面に出す印は `src/data/glyphs.js` が単一の正で、
   **文字として描かれる記号だけ**（☉ ☾ ✦ △ ⊕ ※ …）。色は周りの文字から受け継ぐ。
11. **飾りは SVG でその場に線を引く。画像ファイルを持たない。**
   ウロボロス・六芒星と目・十字の印は `src/components/Ornament.jsx`。色は `currentColor` だけ。
12. **飾りより読みやすさを優先する。** 飾りの線は薄く、文字の下に濃く敷かない。
   当たった語は**白地に黒（反転）**で示す——モノクロで最も強い強調がこれ。
13. **言葉の型とふるまいの型を分ける（`channel`）。** 眉間の凝視・沈黙の圧力・
   捕食者のテンポは**言葉として現れない**ので、貼った文面からは絶対に見つからない。
   `detect.js` は `channel: 'behavior'` を必ず外し、画面は
   「文面からは見つからない型が◯件あります」と**毎回言う**。
   読めないものを読めるふりをしない、が守りたい線。
14. **同じ型を二度足さない。** 世に出回っている呼び名（間欠強化・希少性の原理など）は
   `aka`（名前＋読み）で既存の型に繋ぐ。別名は目次に「→ 本来の型名」として並ぶので、
   その呼び名で調べに来た人も同じ1件に辿り着く。
15. **型（相手のすること）と癖（自分のしていること）を混ぜない。** `habits.js` は別のデータ。
   混ぜると「当たった＝相手が悪い、ではない」の線が崩れる。癖の側でいちばん大事なのは
   **本人を責めないこと**——つけこまれるのはつけこむ側がいるからで、癖は原因ではない。
   「自業自得」「甘い」の類と「性格を変えろ」はテストが弾く。
   その場でできる一手も、**相手の同意が要らないこと**だけにする（返し方と同じ線）。
16. **見抜き方の技法を「使える道具」として置かない。** 表情・言い淀み・反応の速さ・
   目線から嘘を見抜く方法は広く出回っているが、人が嘘を見抜ける割合はコイン投げを
   わずかに上回る程度にとどまる。**当たらない技法を信じると、外れたことにも気づけず、
   何もしていない人を嘘つきだと決めつける。** `myths.js` は
   「よく言われていること」と「分かっていること」を必ず分けて書く。
17. **自分の中で起きること（`states.js`）で診断しない。** 病名を当てない、
   当てはめて判定する仕掛け（チェックリスト）を作らない、本人の弱さの話にしない、
   必ず「人に相談する」へ繋ぐ。この4つはテストが機械チェックする。
18. **人間分析（`people.js`）を属性で分けない。** 元にした文章は 高齢者／女性／男性 で
   ふるまいを分けていたが、そのまま持ち込むと「女性は◯◯」という決めつけの道具になる。
   分けるのは**ふるまい**だけ。その文章自身が結論として挙げていた3つの芯
   （一貫性のなさ・境界線の軽視・責任を取らない）が、性別も年代も問わない共通点。
   元の章立てが実際に持っていた情報は「どこで起きたか」なので、それは**場面**
   （職場／家庭／道・店／子ども連れの場／ネット）として残してある。
   属性でくくる言い方が入っていないことをテストが機械チェックする。
   **元の文章のふるまいを1つも落としていないこと**も、テストが名指しで確かめる。
19. **人間分析の見立てを保存する時は、判定ではなく入力（チェックしたふるまい）を残す**
   （`cases.js`。腰痛ナビのカルテと同じ考え方）。型やふるまいをあとから直しても、
   過去の見立てを読み直せる。**氏名・連絡先の欄を持たず**、呼び名だけ。
   呼び名とメモに混ざった電話番号・メール・リンクは自動で伏せる。
   端末を見られる可能性があるなら本名ではなく呼び名を、と画面に書く。
   **1つ当たっただけで型を出さない**（誰にでも当てはまる）。
   点数・順位・診断名を出さず、出すのは「見たふるまい」と「取れる距離」だけ。
   決めるのは距離であって、その人がどういう人間かではない。
20. **人間分析に型を足したら、`counters`（黒い心理学での対応策）も必ず書く。**
   使い返しに挙げるのは `SELF_DEFENSE_TACTIC_IDS`（こちらが呑まれないための型10件）から。
21. **頼まれたものだけを足す。** 渡された文章を入れる時に、頼まれていない注意書き・制限・
   禁止リスト・見出しを自分の判断で足さない。必要だと思ったら、足す前に一度きく。
22. **同じ画面に2種類の飛び先があるときは、両方に分岐を書く。** 癖と状態、型と芯のように
   1画面に2つのデータが並ぶと、片方の anchor しか見ずに取りこぼす（実際に踏んだ）。
23. **画面に出る文にマークダウンを書かない。** `**強調**` はそのまま「**」と表示される
   （実際に出した）。テストが機械チェックする。

## 構成

```
src/data/tactics.js   型カタログ（単一の正。1件足せば一覧・目次・判定が自動で追従）
src/data/habits.js    つけこまれやすい形（自分の癖。型とは層が違うので混ぜない）
src/data/states.js    長く続いた時に起きること（診断しない・判定の仕掛けを持たない）
src/data/myths.js     当てにならない見抜き方（決めつけを配らないための材料）
src/data/people.js    人間分析（属性ではなくふるまいで分ける）
src/lib/analysis.js   見たふるまい → 近い型（点数を出さない）
src/lib/cases.js      見立ての保存（判定ではなく入力を残す・氏名の欄を持たない）
src/data/replies.js   返し方
src/data/sources.js   出典
src/data/toc.js       目次（各データから自動生成。書き写さない）
src/lib/detect.js     語の一致だけで型を当てる（AIを呼ばない・端末内）
src/lib/privacy.js    個人情報を見つけて札に置き換える
src/lib/records.js    記録（氏名・連絡先を持たない）
src/lib/storage.js    localStorage のみ。**ネットワークに触れない**
src/lib/focus.js      目次から飛んだ先へ運ぶ（React に依存しない）
src/data/glyphs.js    画面に出る印（絵文字を使わない）
src/components/Ornament.jsx  飾りの線画（ウロボロス・六芒星と目・十字）
src/lib/yomi.js       読み・並び・行分け（全アプリ共通の目次ルール）
```

型を1件足すときは `tactics.js` だけを直す。画面にも判定にも if を足さない。
`cues`（判定用の語）は**その型に特徴的な言い回しだけ**にする——
「です」のようにどこにでも出る語を入れると、何を貼っても全部の型が当たって役に立たなくなる
（テストが機械チェックする）。

## 開発

```bash
npm install
npm run dev      # 開発サーバー
npm test         # node --test（125件）
npm run build    # dist/ へ
```

テストはリポジトリ直下の `npm test`（`node --test` の再帰探索）からも実行される。

## これはできない

- 相手が本当に何を考えているかは分からない。分かるのは**言葉が一致したかどうか**だけ。
- 言い方を変えられれば当たらない。**読んで嫌な感じがしたことのほうが確か**。
- 身の危険を感じるとき、その場から離れられないときは、このアプリではなく人に頼る。
  緊急のときは110番、急を要しない警察への相談は #9110、契約・勧誘は消費者ホットライン 188、
  家庭内の支配や暴力は DV相談＋。※番号・名称は変わることがあるので公式の案内で確かめる。
