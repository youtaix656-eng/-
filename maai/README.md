# 間合い（まあい）

恋愛の心理学を、**近づき方**と**気づき方**の両方から扱うアプリ。

公開先：https://youtaix656-eng.github.io/-/maai

「異性を依存させたい」「口説き落としたい」「思いどおりにしたい」で調べに来た人にも、
そのまま読めるようにしてあります。ただし置いてあるのは**やり方ではありません**。

- 近づき方（30件）は、研究で言われている範囲で、**自分の側だけでできること**。
- 思いどおりにする型（31件）は、**どう見えるか・なぜ効いてしまうか**だけ。
  依存させる・断らせない・その日の段取りで決めさせる形を、**気づくための一覧**として置く。
- 同意（8件）は、返事が返事として成り立つ条件。**「お持ち帰り」への答えはここ**。

貼った文面は**この端末の中だけ**で調べます（送信しない・サーバーを持たない）。

## できること

| 画面 | 中身 |
|---|---|
| 近づき方 | 30件を7つの段（出会う数を増やす／話す・聞く／打ち明ける／見え方をととのえる／誘う・確かめる／断られたあと／続ける）で。**確からしさを1件ずつ明示**（くり返し確かめられている／結果が割れている／言われているだけ）。やってみた印は付けられるが**効き目は記録しない** |
| 思いどおりにする型 | 31件を8つのまとまりで。なぜ効くのか・見分け方・言われる形・できること・出典。**言葉に残らない型（距離・席・沈黙・触れ方・連絡の間隔）は文面から当てない** |
| 届いた文面を調べる | 貼ると、当たった型と**当たった語**が出る。本文のどこに当たったかを反転で示す |
| 自分が送る文面を見る | これから送る文章を貼る。使う癖はそのまま人に向く癖になるので、送る前に一度見る |
| 同意 | 8件。言葉で確かめる／あいまいな返事は断り／固まるのは同意ではない／酔っている・眠っているときは数えない／断れない場所での「はい」は数えない／いつでもやめられる／一度の同意は次の同意ではない／年齢と法律のこと |
| 当てにならないテクニック | 10件（吊り橋・ミラーリング・3日ルール・脈ありサイン・ネグ・押せば落ちる・性別の言い切り・血液型・決まった台詞・会い続ければ）。**信じないための材料**として置く |
| 断り方・自分を守る形 | 11件。**言い負かす言葉は置かない**（後述） |
| 自分の側で起きること | こじれやすい癖（10件）と、長く続いたときに自分の中で起きること（6件）。落ち度の話にしない・診断しない |
| 記録 | いつ・どの場面で・どの型に当たったか。相手の名前・連絡先は持たない |
| 目次 | 全166項目を読み順（あ〜ん → A〜Z）で。**世に出回っている呼び名（ラブボミング・間欠強化・ガスライティング・ネグ…）からも引ける** |
| 出典 | 38件。**研究として確かめられたもの**と**研究ではないもの**を分けて並べる |

## 決めていること（触るときはここを守る）

1. **相手を思いどおりにする手順を書かない。** 断らせない言い方・その気にさせる段取りは、
   このアプリのどこにも置かない。書くと、**それを使われる側**がこのアプリを読んでも
   助けにならなくなる。`approach.js` の `how`（自分の側でできること）に
   「酔わせ・押し切・連れ込・既成事実・断らせない…」が入っていないことを
   `test/approach.test.mjs` が機械チェックする。
2. **効き目の大きさを書かない。** 「◯％が落ちる」「必ずうまくいく」は実験の条件次第で
   変わるので、書いた時点で嘘になる。代わりに**確からしさの3段**（`EVIDENCE`）を持ち、
   thin（言われているだけ）には**研究ではない出典を必ず1つ**付ける
   ——そうしないと画面で「研究で確かめられたこと」に見えてしまう。
3. **点数・危険度・順位を付けない・診断しない。** 出せるのは「どの型の言い回しに、
   どの語で当たったか」だけ。相手の性格も、自分の状態も、当てはめて採点しない。
4. **当たった＝相手が悪い、ではない。** 同じ言葉はふつうの恋愛でも使う。
   判定に使った語は必ずそのまま見せる（見せない判定は当てずっぽうの断定と同じ）。
5. **当たらなくても黙らない。** 「短すぎて調べられない」「当たらなかった」を言い分け、
   当たらない＝問題がない、ではないことも画面に書く。
6. **読めないものを読めるふりをしない。** 距離・席・沈黙・触れ方・連絡の間隔で効く型
   （`channel: 'behavior'`）は言葉として現れないので、`detect.js` が渡されても必ず外し、
   画面は「文面からは見つからない型が◯件あります」と毎回出す。
7. **断り方に「言い負かす言葉」を置かない。** 恋愛の言い合いは、たいてい強く出られる側が
   勝つ。置くのは**相手の同意が要らないこと**だけ——間を置く・自分の足で帰る・
   自分の飲み物を持つ・場所を自分で決める・人に話す・記録する・離れる・窓口に聞く。
8. **出典に URL を書かない。** 確かめられない状態でそれらしいリンクを書くのは、
   出典があるように見えて実は無いという、いちばん質の悪い形になる（Ouro `docs/PROMPT.md`
   項目88と同じ事故）。書名・発表者・年で辿れる形にし、確かめきれていないものは
   `check: true` で「※要確認」を出す。
9. **研究でないものを研究のふりをさせない。** 経験として言われているだけのこと・
   このアプリが置いている決めごと・窓口の案内は `research: false` として分け、
   画面にも「（研究ではありません）」と出す。
10. **法律の数字をアプリに持たない。** 年齢の線・要件は改正で変わる。書くと
    古い数字が根拠として使われるので、公式（法務省・警察・自治体）で確かめる、と書く。
11. **性別で決めつけない。** 「男は◯◯・女は◯◯だから効く」は、当てにならないテクニックの
    側に置く。近づき方・型・同意のどれも、誘う側／誘われる側の両方に同じことが掛かる。
12. **癖（`habits.js`）で本人を責めない。** つけこまれるのは、つけこむ側がいるからで、
    癖は原因ではない。性格を変えろとも書かない。その場でできる一手だけを書き、
    その一手も**相手の同意が要らないこと**に限る。
13. **状態（`states.js`）で診断しない。** 病名を当てない・チェックリストで点数を出さない・
    本人の弱さの話にしない・必ず人（相談先）へ繋ぐ。
14. **画面に出す文にマークダウンを書かない**（`**強調**` がそのまま表示される。鏡で実際に出した）。
    強調は JSX 側の `<strong>` で行う。
15. **`src/lib/` はネットワークに触れない。** 貼った文面が端末から出ないことの根拠。
    テストが `fetch` などの不在を見る。
16. **後読み（lookbehind）を使わない**（古い Safari が読み込みごと落ちる。鏡・Ouro と同じ）。
17. **色を持たない・絵文字を使わない・画像ファイルを持たない。** 黒地に白い線の銅版画。
    画面に出す印は `src/data/glyphs.js` が単一の正、飾りは `Ornament.jsx` がその場で線を引く。

## 目次から飛ぶときの注意（実際に踏んだ）

目次から飛ぶと、飛び先の画面が「開く／絞り込む」の状態を作ってから、
`lib/focus.js` の `flashTo` がその要素まで運んで一瞬光らせる。
このとき、**状態を作る副作用は `useLayoutEffect` で行うこと**
（`Approach.jsx` / `Tactics.jsx`）。`useEffect` にすると、開く描き直しが
光らせる処理（次のフレーム）より後になることがあり、React が `className` を
書き直した拍子に `flash` が消える（実際にこの状態になっていた）。

また、**「画面の先頭へ戻す」を副作用にしない**——目次から飛んだ直後に focus を
空へ戻すので、「focus が空なら先頭へ」を置くと飛び先から引き戻される（鏡と同じ）。

## 層を混ぜない

| 層 | ファイル | 何の話か |
|---|---|---|
| 近づき方 | `data/approach.js` | 自分が動かすこと |
| 型 | `data/tactics.js` | 相手がしてくること（＝自分がしてしまうかもしれないこと） |
| 同意 | `data/consent.js` | 返事が成り立つ条件 |
| 癖 | `data/habits.js` | 自分がしていること |
| 状態 | `data/states.js` | 自分の中で起きていること |
| 当てにならないテクニック | `data/myths.js` | 出回っている思い込み |

混ぜると「当たった＝相手が悪い」の線が崩れる（鏡と同じ理由）。

## 開発

```
npm install
npm run dev      # 開発サーバー
npm run build    # ビルド（GitHub Pages のサブパス配信のため base: './'）
npm test         # node --test（現在93件）
```

データを1件足せば、一覧・目次・貼って調べる・出典の逆引きが自動で追従する。
**画面にも判定にも if を足さない。**
