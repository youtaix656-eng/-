# MVPの選定（機能30・システム30の判定）

企画で挙がった60件を **第1弾 / 第2弾 / 第3弾以降 / 作らない** に分けたもの。
「作らない」は消したのではなく、**作らない理由を残す**ためにここに置いてあります
（同じ提案が半年後にまた出てくるのを防ぐため）。

判定に使った線は `../README.md` の「決めていること」12項目。

---

## 機能30件

### 📊 記録・トラッキング系

| 機能 | 判定 | 理由・変えたところ |
|---|---|---|
| 便通カレンダー（ブリストル7段階） | **第1弾** | 芯。回数と時刻も持つ（IBSの診断基準が頻度を見るため） |
| お腹の調子スコア（5段階） | **第1弾**（名前を変える） | 「スコア」をやめて**5つの段**に。点数化しない（決まり2） |
| 食事×お腹の相関記録 | **第1弾は記録まで** | 記録は第1弾、**相関の提示は第2弾**。2週間ぶん貯まる前に相関を出すと、たまたまを因果に見せる |
| ガス・膨満感トラッカー | **第1弾**（統合） | 別画面にせず「今日の記録」の項目に。トラッカーを分けるほど記録が続かなくなる |
| ストレス×腹痛の相関グラフ | 第2弾 | ストレスの段を記録する項目を先に置く。グラフは**並べるだけ**で、矢印（→）を書かない |
| 水分摂取量記録 | 第2弾 | 「1日◯L」の基準は持たない（決まり3）。自分の平均との差だけ |
| 睡眠×腸内環境の相関 | 第2弾 | 同上。**「腸内環境」とは書かない**——測っていないので。書くのは「睡眠とお腹の調子」 |

### 🍽️ 食事・栄養系

| 機能 | 判定 | 理由・変えたところ |
|---|---|---|
| 低FODMAP食材チェッカー | **第1弾**（一覧として） | 食材の一覧＋出典＋最終確認日。**料理名から判定するAIは持たない**（下段） |
| 発酵食品レシピ集 | 第3弾 | レシピは量が要る割に、記録の継続には効かない。外部のレシピへ繋ぐ形も検討 |
| 水溶性/不溶性の食物繊維バランス提案 | 作らない（形を変える） | 「◯:◯が理想」は出典で割れる（決まり3）。**どちらを多く食べた日か**を並べるだけにする |
| 腸活おすすめレシピ（酪酸菌） | 第3弾 | 「酪酸菌を増やす食材」は言われている段階のものが混ざる。書くなら確からしさを1件ずつ明示 |
| 外食・コンビニの選び方 | 第2弾 | 実用性が高い。**特定チェーンの商品名を持たない**（変わり続けるので必ず古くなる） |
| サプリ・整腸剤の飲み合わせチェック | **作らない** | 外れたときの害が大きく、手元に基準が無い。「薬剤師・医師に聞く」へ繋ぐ一文だけ置く |

### 🩺 医療・症状理解系

| 機能 | 判定 | 理由・変えたところ |
|---|---|---|
| 症状セルフチェック（緊急度判定） | **形を変えて第1弾** | 赤/黄/緑で判定しない（決まり1）。**受診の目安の一覧**として置き、数えない・順位を付けない |
| お腹の病気図鑑（IBS・潰瘍性大腸炎・クローン病） | 第2弾 | 自分の症状と照らして**当てはめる仕掛けを作らない**（読み物として置くだけ） |
| 薬の副作用データベース | **作らない** | 添付文書の写しは、古くなった時にいちばん危ない。公的な検索へ繋ぐだけ |
| 受診時の症状メモ作成 | **第1弾** | このアプリを持つ理由。記録から組み立ててコピー・書き出し |
| 腸内フローラの基礎知識辞典 | 第2弾 | 数値と断定を外して。「◯％が善玉菌」の類は書かない |
| 加齢と腸の変化 | 第3弾 | 読み物。急がない |

### 🧘 生活習慣・セルフケア系

| 機能 | 判定 | 理由・変えたところ |
|---|---|---|
| 腹式呼吸・お腹マッサージ | 第2弾 | 図はその場にSVGで描く（画像ファイルを持たない）。**痛みが強い時はしない**を必ず添える |
| IBSタイプ別セルフケア | 第2弾 | タイプは**自己申告で選ぶ**。自動分類しない（下段） |
| トイレの場所マップ | 要相談 | 位置情報＝端末内保存方針の例外。`README.md`「あとで決めること」1 |
| リラックス音声・瞑想 | 第3弾 | 音声ファイルを持つと重くなる。端末の音声合成で読み上げる形なら第2弾 |
| 朝活腸活ルーティン提案 | 第2弾 | 「起きて◯分以内に」の類の数字は持たない |
| 旅行・環境変化時のチェックリスト | 第2弾 | IBSで実際に効く。チェックの中身は自分で足せるように |

### 👥 コミュニティ系

| 機能 | 判定 | 理由 |
|---|---|---|
| 匿名お悩み相談掲示板 | 要相談 | サーバーが要る＋医療デマと自傷の見張りを誰が負うか。`README.md`「あとで決めること」2 |
| 腸活チャレンジ（21日間） | 第3弾 | 「21日で習慣になる」は根拠の弱い通説。期間を書くならその旨を添える |
| バッジ・継続日数表示 | **形を変えて第1弾** | 連続日数を煽らない（決まり5）。出すのは**通算の記録日数**と2週間の埋まり具合 |

### 🎨 デザイン・UX系

| 機能 | 判定 | 理由 |
|---|---|---|
| 腸のキャラクターの表情変化 | **第1弾** | 責める顔を持たない（決まり9）。SVGでその場に描く |
| 朝のワンタップ記録UI | **第1弾** | これが無いと他の全部が意味を持たない |

## システム30件

### 🗄️ データ・記録系

| システム | 判定 | 理由 |
|---|---|---|
| 統一記録データベース設計 | **第1弾** | `docs/SCREENS.md` の「データの持ち方」。日付キー1本にそろえる |
| ブリストルスケール判定エンジン | **作らない**（人が選ぶ） | 7つの絵から本人が選ぶだけ。判定するものが無い |
| 相関分析エンジン | 第2弾（弱く） | **相関を因果として書かない**。「◯を食べた日は△が多かった（◯日ぶん）」まで |
| 時系列グラフ生成 | **第1弾**（素のSVG） | 外部ライブラリを入れない（このリポジトリ共通） |
| ワンタップ入力 | **第1弾** | 芯 |
| オフライン記録→自動同期 | 第3弾 | 同期先を持つとサーバーが要る。まずは端末内＋手動の書き出し |

### 🤖 AI・判定系 — ここはほぼ作らない

| システム | 判定 | 理由 |
|---|---|---|
| 症状セルフチェックAI（赤/黄/緑） | **作らない** | 診断行為に近く、緑と出た人が受診をやめる。決まり1 |
| 低FODMAP食材判定AI | **作らない** | 料理名からの推定は必ず外れる。食材の一覧（出典つき）で足りる |
| 食事写真解析 | **作らない** | 読めないものを読めるふりをしない（決まり4）。写真は写真のまま貼る |
| IBSタイプ自動分類 | **作らない** | 分類＝診断。本人が選ぶ（選び直せる） |
| パーソナライズ提案エンジン | 第2弾（弱く） | 提案するのは**自分の記録から言えること**だけ。「あなたに合う菌」は書かない |
| 薬・サプリ飲み合わせAPI | **作らない** | 上と同じ |

### 🔔 通知系

| システム | 判定 | 理由 |
|---|---|---|
| 記録忘れ防止プッシュ通知 | 要相談 | サーバーが無いので、出せるのはアプリが開いている間だけ。できることだけ書く |
| 異常検知アラート | **作らない** | 「異常」を機械が言い切る形。代わりに**受診の目安**を本人がいつでも読める場所に置く |
| 服薬リマインダー | 第3弾 | 上と同じ制約 |
| チャレンジ進捗通知 | 第3弾 | — |
| 通院予定リマインダー | 第2弾 | 予定は端末内に持てる（通知は上の制約つき） |

### 🗺️ 位置情報・外出支援

|---|---|---|
| トイレマップGPS連携 | 要相談 | `README.md`「あとで決めること」1 |

| 旅行モード自動切替 | 第3弾 | 位置で自動切替＝位置を持つこと。手で切り替える形なら第2弾 |

### 📚 コンテンツ系

| レシピDB＋フィルター | 第3弾 | — |
| 動画/音声配信 | **作らない** | 配信＝サーバー。端末の音声合成で代替 |

### 👥 コミュニティ系

| システム | 判定 | 理由 |
|---|---|---|
| 匿名掲示板 | 要相談 | `README.md`「あとで決めること」2 |
| 通報・モデレーション | 掲示板とセット | **掲示板を作るならこれも同時**。片方だけは作らない |
| バッジ・継続日数トラッキング | 形を変えて第1弾 | 連続日数を煽らない（決まり5） |

### 🩺 医療連携 / 🎨 UI基盤

| システム | 判定 | 理由 |
|---|---|---|
| 受診サマリー自動生成 | **第1弾** | 芯。テキストで組み立ててコピー＋書き出し |

## まとめ

60件すべてに判定が付いています（下は判定の行数。機能とシステムで同じものを両側から
挙げているぶん――ワンタップ入力・キャラクター・受診メモ――は二重に数えています）。

| 段 | 行数 | 中身 |
|---|---|---|
| **第1弾（MVP）** | 16 | 記録 → カレンダー → ふりかえり → 受診メモ の一本道＋低FODMAP一覧・受診の目安・キャラクター |
| 第2弾 | 15 | 相関の提示・読み物・セルフケア・外出 |
| 第3弾以降 | 12 | レシピ・チャレンジ・外部連携 |
| **作らない** | 11 | 判定AI・写真解析・薬DB・異常検知・配信・繊維バランスの理想値 |
| 要相談 | 6 | トイレマップ・掲示板・通報／モデレーション・通知3種 |
